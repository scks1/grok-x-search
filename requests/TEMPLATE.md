# Request template

Copy this file to `requests/request-NNN.md`, fill in every field, add a row
to `requests/INDEX.md` with status QUEUED.

- **ID:** request-NNN
- **Date queued:** YYYY-MM-DD
- **Surface:** X (Twitter)
- **Scope / queries:** the searches to run (topics, phrases, accounts,
  date windows)
- **Buckets:** which of BRIEF.md's buckets apply (default: all three, in
  priority order)
- **Special focus:** anything this run should weight more heavily, or
  "none"
- **Status:** QUEUED | DONE
- **Result:** (filled in on completion) results/YYYY-MM-DD-run-N.md
